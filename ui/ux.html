    Model & Pipeline

    KardioNet-CNN v2.3 — klasifikasi biner HFpEF vs HFrEF berbasis scalogram CWT dengan interpretabilitas Grad-CAM.

    ① Preprocessing

    Detrending baseline wander, filter lolos-pita 0,5–40 Hz, notch 50 Hz, kalibrasi unit otomatis, dan pemotongan jendela 10–12 detik.

    ② Continuous Wavelet Transform

    Sinyal 1-D dikonversi menjadi scalogram waktu–frekuensi 2-D memakai wavelet Morlet (ω₀ = 6) pada 56 skala geometris ≈ 1–121 Hz.

    ③ Inferensi CNN

    Empat blok konvolusional + batch normalization + dropout, diakhiri softmax 2 neuron. Grad-CAM menampilkan peta atensi model.

    Arsitektur Jaringan

    ≈1,2 juta parameter
    • 00Input — scalogram CWT224×224×3
    • 01Conv2D 32@3×3 + BN + ReLU + MaxPool112×112×32
    • 02Conv2D 64@3×3 + BN + ReLU + MaxPool56×56×64
    • 03Conv2D 128@3×3 + BN + ReLU + MaxPool28×28×128
    • 04Conv2D 256@3×3 + BN + ReLU + MaxPool14×14×256
    • 05GlobalAveragePooling + Dropout 0,4256
    • 06Dense 128 + ReLU + Dropout 0,3128
    • 07Dense 2 + Softmax → HFpEF / HFrEF2
